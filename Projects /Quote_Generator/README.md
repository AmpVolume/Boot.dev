Project Purpose The purpose of this project is to:

Practice core Python concepts in a clean, readable way

Demonstrate the use of the standard library (random)

Provide a simple example of a CLI (command-line interface) Python program

Serve as a foundation that can be easily extended (e.g., adding file input, APIs, or user interaction)

Each execution of the script selects and prints one quote at random from a predefined collection.

Technologies Used Python 3 Standard Library Module: random No external dependencies are required.

How to Run the Project (Terminal)

Clone the Repository git clone https://github.com/your-username/quote-generator.git

Navigate to the Project Directory cd quote-generator

Run the Script python quote_generator.py

If your system uses python3 instead of python, run:

python3 quote_generator.py

Example Output The best way to predict the future is to invent it. — Alan Kay

Each run will display a different quote.
